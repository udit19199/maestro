# Product

Zoro is a native macOS app for conversations with bots running through pi RPC. The first bot is Projects Manager. Projects and tasks belong in Notion. Specialist delegation is not implemented yet.

Bots are configured separately from chats. Users can switch the selected bot between messages without losing conversation history.

The main window contains the conversation sidebar and the selected conversation. Settings stays in the same window. Providers lists pi-supported providers; MCP servers lists integrations supported by Zoro, starting with Notion. Users connect through the UI, without terminal commands.

Bot creation, Memory, mail, calendar, and remote messaging are outside the current scope.
